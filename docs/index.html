What the experiments changed

Current product model

Artifacts → Memories → Stories → Chapters → Life of a Bike

The memory—not the finished story—is now the atomic unit of capture. BikeStories should preserve incomplete evidence, discover relationships over time, and only construct a higher-order story when the material actually supports one.

Preserve first. Organize when confident. Tell a story only when one is actually there.

Next research directions

Planned experiment

No-story / random-photo test

Give the system a messy set of photographs of the same bicycle that do not form one coherent narrative. Test whether it can preserve and lightly cluster the material without manufacturing a story.

Planned experiment

External source discovery

Point BikeStories at a larger existing photo source such as a Flickr album. Test whether it can search broadly for candidate memories or stories and pull in only the artifacts that actually contribute.

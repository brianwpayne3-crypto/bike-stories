Voyager Experiment 003

Can AI discover the story that is actually there?

A blinded story-understanding experiment using the same frozen Voyager photographs, first with images alone and then with ordinary owner context.

What we tested

This experiment deliberately ignored visual design. The question was whether AI could infer useful narrative relationships among real artifacts without being told how the pictures should be sequenced or what each one meant.

Pass A · photos only

The model found a convincing visual skeleton and interpreted the material as a rediscovery/restoration/recommissioning story. It was disciplined about unsupported personal meaning, but the overall narrative frame was too dramatic.

Pass B · photos + owner context

Ordinary context substantially improved the interpretation. The model reframed the material around a smaller tension between preservation and use: a cheap, complete old touring bike with unusual provenance, kept mostly original while selectively changed for comfort.

The failure that mattered

The visually obvious ending was wrong.

In both passes, the riding POV looked like a natural payoff. Owner correction later established that the ride happened before some of the changes. The current/latest bike image also still shows unfinished work. The evidence pile did not actually contain the clean finished-state ending the model thought it saw.

That matters because a photograph can be authentic, attractive, and narratively plausible while still being wrong for a particular story role.

What changed in the product model

Artifacts → Memories → Stories → Chapters → Life of a Bike

Voyager 003 helped expose a category error in the earlier approach: BikeStories was trying too hard to turn one source dump into a finished Story. The safer model is that the dump may only support a Memory. A later memory may complete it, contradict it, or reveal the larger story.

The working rule became:

Preserve first. Organize when confident. Tell a story only when one is actually there.

Research findings

Visual plausibility is not enough to establish chronology. Artifact selection and narrative sequencing are separate editorial tasks. Owner context can materially change the interpretation of identical source material. The system needs to tolerate unfinished memories and should be able to conclude that there is no coherent story yet.

What this points to next

Two follow-on tests are now particularly important. One should give BikeStories a messy collection of same-bike photographs where there genuinely is no single story and test whether it resists manufacturing one. Another should point the system at a larger external source—such as a Flickr album—and test whether it can search broadly for candidate memories or stories while selecting only the artifacts that actually contribute.

The frozen Pass A and Pass B artifacts are preserved in the repository under experiments/voyager-003/.
